# Living study

The profile window follows **New York** weather and local sunrise/sunset. The scene
is generated by GitHub Actions at minutes 17 and 47 each hour, and on manual runs.
Schedules can be delayed by GitHub; refresh the profile to see updated assets.
The banner keeps only the name visible. Weather and observation time remain in
the SVG description and `assets/study-state.json`. A failed fetch or invalid
response leaves the previous image in place.

Weather data comes from [Open-Meteo](https://open-meteo.com/) under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). These are modeled current
conditions, not a live sensor feed. No API key, visitor tracking, or precise personal
location is used. All visitors see the same configured city.

## Configuration

Edit `study.json` to change the display city, coordinates and IANA time zone.
Only public city coordinates belong in this file. The script uses Unix timestamps
and `zoneinfo` for daylight saving time. Dawn/dusk span 30 minutes on either side
of the day's sunrise/sunset. Otherwise the scene is day or night; it does not
follow the visitor's GitHub theme.

The scene supports clear, cloud, rain, snow, fog and storm weather. Storms use
clouds and rain without flashing lightning. CSS animation handles the cat, steam
and weather; reduced-motion preferences disable those animations.

The notebook uses GitHub's native `<details>` interaction. Embedded SVGs cannot
execute JavaScript or offer individual click targets for the lamp or cat.

## Maintenance

Python 3.9+ with system time-zone data is sufficient; no pip dependencies.

```sh
python3 -m unittest discover -s tests -v
python3 scripts/update_scene.py
```

The workflow only stages the two generated SVGs and weather state, and commits
as `github-actions[bot]`. Unchanged output is not committed. GitHub may disable
scheduled workflows after 60 days without repository activity; the Actions tab
allows re-enabling the workflow and running it manually.
